# 配置指南

## 本地配置

项目本地已有 `include/config.h` 占位副本，与模板相同，无真实凭据，已被 `.gitignore` 排除。从仓库克隆时使用：

```powershell
Set-Location <your-project-path>
# 仅 config.h 不存在时复制，避免覆盖已填信息。
if (-not (Test-Path -LiteralPath include\config.h)) {
    Copy-Item -LiteralPath include\config.example.h -Destination include\config.h
}
```

| 字段（按模板顺序） | 填写方式 |
|---|---|
| ssid | 家中 2.4GHz Wi-Fi 名称，最长 32 字节 |
| password | WPA/WPA2 家庭密码，8～63 字节；本版不支持开放网络/企业 Wi-Fi |
| uid | 控制台 32 位十六进制私钥，作为认证 Client ID；不上传、不贴日志 |
| topic | 已有主题的真实值，不是中文昵称；大小写一致，1～64 字节字母/数字/下划线 |
| protocol | 核实后用 `Protocol::Mqtt`；默认 `Unconfirmed` 安全停机；TCP 本版未实现 |
| transport | 默认 `Transport::Tls`，9503 |
| allowPlaintext | 默认 false；仅显式开发明文测试时和 PlaintextDevelopment 一起设为 true |
| rootCa | 默认 `kBemfaRootCa`；公开证书，不是账号密钥 |
| targetMac | 家用台式机**有线**网卡 MAC，不能填开发笔记本或 Wi-Fi 网卡地址 |
| broadcast | 默认空串，实时自动计算；手动值须为同子网广播或 255.255.255.255 |
| udpPort / repeats / repeatIntervalMs | 默认 9 / 3 / 100ms；重复 1～10 次，间隔 10～1000ms |
| cooldownMs / reconnectGuardMs / armWindowMs | 默认 15000 / 3000 / 10000ms，分别为请求冷却、重连保护、off到on授权有效期 |

字符串中的双引号和反斜杠需使用 C++ 转义。修改后重新 USB 烧录；没有 Web 配网或 OTA。配置校验只打印错误字段名，不打印字段内容。缺少文件时编译回退模板；运行时模板/错误字段会触发 `SAFE STOP`，不会启动 Wi-Fi、云连接或 WOL。

## 必须确认主题协议

1. 在用户自己的巴法云控制台查看**已有主题**位于 MQTT 设备还是 TCP 设备列表。
2. 主题名的后三位 006 等决定设备 UI 类型，不能证明它属于 MQTT。API type=1 才代表 MQTT、type=3 代表 TCP。
3. 若已有主题属于 MQTT，原样填入并将 protocol 改为 Mqtt。
4. 若属于 TCP，保留现有主题，记录协议类型；本固件将拒绝启动。后续需适配 TCP，或由用户决定平台侧方案，不能擅自新建/删除主题。
5. 本次尚未提供主题值或控制台证据，协议保持待确认，没有声称已接入用户账号。

参考：[官方 MQTT 认证](https://cloud.bemfa.com/docs/src/mqtt.html)、[设备 API 协议类型](https://cloud.bemfa.com/docs/src/api_device.html)、[类型后缀](https://cloud.bemfa.com/docs/src/index_device.html)。

## 官方客户端操作

上电后先确认串口依次出现 Wi-Fi IP、TLS校时、MQTT connected / SUBACK。重连成功后至少等 3 秒；每次唤醒先点关闭 `off`，随后在 10 秒内点开启 `on`。再次唤醒需距上次接受请求至少 15 秒，再重做 off/on。关闭指令永远不关机。

APP 若当前显示“关”，点击关闭是否仍会发送 `off` 需实测；如果 UI 无法发出必要的 off，可先点开（未授权会忽略），再点关、再点开。保护期内点击全部丢弃，不能提前授权。

不建议用同一个 UID 同时连接 mqtt.fx 或另一块板；Client ID 冲突可能互踢。调试时先退出其他 MQTT 客户端。

## 串口诊断

| 日志 | 含义 / 操作 |
|---|---|
| SAFE STOP: check field | 编辑本地对应字段，再编译烧录 |
| waiting for SNTP | 未得到有效时间；检查 DNS、UDP123、家庭路由器外网 |
| connect/subscribe failed | 检查 TLS链、UID、MQTT主题和 Client ID 冲突；数值 connectError=4/5 常涉及认证或权限 |
| SUBACK granted QoS0 | 已订阅成功，等待保护期后 off/on；仍不表示电脑开机 |
| startup/reconnect guard | 等 3 秒后重做 off/on |
| fresh off required | 先发 off 再发 on |
| retained state/history / MQTT DUP | 拒绝历史/重复，不应为让开关生效而关闭校验 |
| cooldown | 等冷却结束，重新 off/on，先前操作不排队 |
| local UDP sends completed | 仅本地发包结果，电脑状态 UNKNOWN |

日志不打印原始消息、UID、密码。分享日志前仍请遮盖家用 IP 或其他个人信息（如需）。填入真实配置后，固件二进制也含凭据；勿 `git add -f` 上传 config.h、.pio、bin/elf。
